# Draft Materials

This directory serves as the staging folder for unconfirmed meeting materials and upcoming topics. It collects draft presentations, podcast discussions, and infographics comparing different software design schools of thought.

## Clean Code vs. Deep Software Design Debate

The current draft materials focus on the architectural debate between Robert Martin (author of *Clean Code*) and John Ousterhout (author of *A Philosophy of Software Design*).

### Draft Slide Decks
- **Architectural Civil War:** Slides mapping the exact points of conflict between the tactical "small functions" rule and the strategic "deep modules" philosophy.
- **Software Design Noir:** A narrative presentation on the hidden costs of tactical programming and codebases built around shallow abstractions.
- **The Deep Temple Quest:** Slides detailing practical guidelines for hiding information, defining deep interfaces, and designing complexity sinks.

### Discussion Recordings
- **Ousterhout vs. Uncle Bob Deep Dive:** A conversation exploring the root causes of disagreement on readability and design.
- **Ousterhout vs. Uncle Bob Critique:** An analytical review highlighting where both authors make valid assumptions and where their heuristics break down in practice.
- **Clean Code vs. Deep Software Design:** A podcast dissecting the physical layout of classes and functions when applying both design methodologies to the same project.

### Visual Infographics
- **Martin-John Debate Infographic:** A visual comparative matrix highlighting core design principles, contrasting function size, class design, and naming conventions.
