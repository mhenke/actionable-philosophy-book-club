# AI Prompt Library

Standardized prompt frameworks for generating meeting materials from discussion transcripts.

## Prompts

- [Five Essential Questions](five-essential-questions-prompt.md) — generate the key questions for a session from source material
- [Non-Obvious Insights](non-obvious-inisght-prompt.md) — extract counterintuitive takeaways from discussion notes
- [Slide Deck](slide-deck-prompt-template.md) — structure a slide deck outline from session themes

## Usage

Each prompt is a template — replace the bracketed placeholders with session-specific content before submitting to an AI assistant.
