# AI prompt library

Prompts we use to turn session transcripts into meeting materials.

## Prompts

- [Five Essential Questions](five-essential-questions-prompt.md): pull the key questions out of source material
- [Non-Obvious Insights](non-obvious-inisght-prompt.md): find counterintuitive takeaways from discussion notes
- [Slide Deck](slide-deck-prompt-template.md): outline a slide deck from session themes
- [Anime Temple Essential Questions Deck](anime-temple-essential-questions-deck.md): slide deck with 5 essential questions framed through an anime adventurer temple metaphor

## Usage

Each prompt is a template. Replace the bracketed placeholders with session-specific content before sending it to an AI assistant.
