# Design Principles

Our approach to documentation, collaboration, and repository management.

## ⚖️ Core Values

### 1. Simplicity Over Ceremony
- Keep documentation concise and accessible.
- Favor Markdown for everything.
- Automate repetitive tasks (like compression) to lower the barrier for contribution.

### 2. Action-Oriented Learning
- Focus on practical applications of software philosophy.
- Use "Essential Questions" to drive discussion.
- Apply the concepts we read to our own codebase and repository.

### 3. AI-Augmented Productivity
- Leverage AI to enhance our learning (summaries, insights).
- Use AI for repository maintenance (standardization, housekeeping).
- Document AI prompts to share "Meta-skills" with the team.

### 4. Transparency and Async Collaboration
- Document every meeting.
- Use the Inbox (`meeting-99-new`) for emerging ideas.
- Ensure all assets are discoverable via READMEs and TOCs.
