# Review Scope

## Target

Full project review of the Actionable Philosophy Book Club web app — a static single-file SPA
(index.html) backed by markdown content, served via GitHub Pages.

## Files

### Primary (application code)
- `index.html` — entire app: dashboard view, reader view, CSS design system, JS routing + markdown rendering

### Content / Docs
- `meetings/meeting-00/README.md`
- `meetings/meeting-01/README.md` + `01-essential-questions.md` + `01-non-obvious-insights.md`
- `meetings/meeting-02/README.md` + `02-essential-questions.md` + `02-non-obvious-insights.md`
- `meetings/meeting-03/README.md`, `meetings/meeting-04/README.md`
- `docs/glossary.md`, `docs/design-principles.md`
- `docs/adr/0001-powerpoint-viewer-selection.md`, `docs/adr/0002-single-page-reader.md`
- `templates/` — meeting, discussion, AI prompt templates

### Project meta
- `PRODUCT.md`, `DESIGN.md`, `README.md`, `CONTRIBUTING.md`

## Flags

- Security Focus: no
- Performance Critical: no
- Strict Mode: no
- Framework: vanilla HTML + Tailwind CDN + marked.js

## Review Phases

1. Code Quality & Architecture
2. Security & Performance
3. Testing & Documentation
4. Best Practices & Standards
5. Consolidated Report
